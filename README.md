# 求人広告 応募獲得力分析ツール

求人広告の「応募獲得力」をAIで可視化し、改善のための次の一手を明確にするWebアプリケーションです。

## 特徴

### 🎯 プロダクト思想

- **全否定しない**: 0点や否定的評価は行わず、必ず良い点を見つけます
- **行動重視**: 改善点は具体的なアクションとして提示
- **変化を可視化**: 点数だけでなく、改善による応募数への影響を表示
- **2フェーズ処理**: 分析と長文生成を分離し、レスポンスを最適化

### ✨ 主な機能

1. **応募獲得力の分析**
   - 総合スコア（40-100点）
   - タイトル、仕事内容、条件・待遇、魅力の4軸評価
   - ステータス表示（excellent / good / needsImprovement）

2. **Good Pointsの提示**
   - 必ず1つ以上の良い点を発見
   - ポジティブなフィードバック

3. **改善提案**
   - 具体的な行動として提示
   - 改善インパクト（応募数への影響目安）を表示
   - 優先度が明確

4. **次の一手**
   - 今すぐ実行すべき1つのアクションを提示
   - 迷わず行動できる

5. **改善サンプル生成（オプション）**
   - 分析結果をもとに改善版の求人原稿を生成
   - ボタン1つで実行

## セットアップ手順

### 1. Google Cloud Platformの設定

1. [Google Cloud Console](https://console.cloud.google.com/)にアクセス
2. 新しいプロジェクトを作成、または既存のプロジェクトを選択
3. **Vertex AI API**を有効化
   - 「APIとサービス」→「ライブラリ」
   - "Vertex AI API"を検索して有効化

### 2. Google Apps Scriptプロジェクトの作成

1. [Google Apps Script](https://script.google.com/)にアクセス
2. 「新しいプロジェクト」を作成
3. プロジェクト名を設定（例: "求人広告分析ツール"）

### 3. ファイルのアップロード

以下のファイルをGoogle Apps Scriptプロジェクトに追加します：

1. **appsscript.json**
   - プロジェクト設定 > 「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック
   - 内容を置き換え

2. **Code.gs** - メインバックエンド
3. **VertexAI.gs** - Vertex AI連携モジュール
4. **Analyzer.gs** - 求人分析ロジック
5. **index.html** - フロントエンドUI

### 4. GCPプロジェクトのリンク

1. Google Apps Scriptエディタで「プロジェクトの設定」（⚙アイコン）を開く
2. 「Google Cloud Platform (GCP) プロジェクト」セクションで「プロジェクトを変更」
3. 手順1で作成したGCPプロジェクトの**プロジェクト番号**を入力
4. 「プロジェクトを設定」をクリック

### 5. スクリプトプロパティの設定

1. Google Apps Scriptエディタで「プロジェクトの設定」を開く
2. 「スクリプト プロパティ」セクションで以下を追加：

| プロパティ | 値 | 説明 |
|----------|-----|------|
| `VERTEX_AI_PROJECT_ID` | あなたのGCPプロジェクトID | 必須 |
| `VERTEX_AI_LOCATION` | `us-central1` | オプション（デフォルト: us-central1） |

**プロジェクトIDの確認方法**:
- Google Cloud Console > ダッシュボード > 「プロジェクト情報」カードで確認

### 6. OAuth認証の設定

1. Google Apps Scriptエディタで任意の関数（例: `checkConfiguration`）を実行
2. 「権限を確認」→ Googleアカウントでログイン
3. 「詳細」→「（プロジェクト名）に移動」→「許可」

### 7. デプロイ

1. エディタ右上の「デプロイ」→「新しいデプロイ」
2. 「種類の選択」で「ウェブアプリ」を選択
3. 設定:
   - **説明**: 任意（例: "初回デプロイ"）
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 全員
4. 「デプロイ」をクリック
5. **WebアプリのURL**をコピー

### 8. アクセス

デプロイ時に取得したURLにアクセスして、アプリが正常に動作するか確認します。

## 使い方

### 基本的な使い方

1. **求人広告を入力**
   - テキストエリアに求人広告の内容を貼り付け
   - または直接入力

2. **分析開始**
   - 「分析開始」ボタンをクリック
   - 15-30秒ほど待機

3. **結果を確認**
   - 応募獲得力ステータス
   - 総合スコア
   - Good Points
   - 改善提案（インパクト付き）
   - 次に取るべきアクション
   - スコア詳細（折りたたみ）

4. **改善サンプルを生成（オプション）**
   - 「改善サンプル原稿を生成」ボタンをクリック
   - 改善版の求人原稿が生成されます

### キーボードショートカット

- **Ctrl + Enter**: 分析を実行

## トラブルシューティング

### エラー: "VERTEX_AI_PROJECT_IDが設定されていません"

**原因**: スクリプトプロパティにプロジェクトIDが設定されていない

**解決策**:
1. 「プロジェクトの設定」→「スクリプト プロパティ」
2. `VERTEX_AI_PROJECT_ID`を追加し、GCPプロジェクトIDを入力

### エラー: "AI処理に失敗しました"

**原因1**: Vertex AI APIが有効化されていない

**解決策**:
1. Google Cloud Consoleで該当プロジェクトを開く
2. 「APIとサービス」→「ライブラリ」
3. "Vertex AI API"を検索して有効化

**原因2**: GCPプロジェクトがリンクされていない

**解決策**:
1. Apps Scriptの「プロジェクトの設定」を開く
2. GCPプロジェクト番号を正しく設定

**原因3**: OAuth権限が不足

**解決策**:
1. Apps Scriptエディタで`checkConfiguration`関数を実行
2. 権限を再承認

### エラー: "分析に失敗しました: 入力が短すぎます"

**原因**: 求人広告の内容が10文字未満

**解決策**: もう少し詳しい求人内容を入力してください

### 分析に時間がかかる

**正常な動作**: Vertex AI APIの呼び出しには15-30秒程度かかります

**確認ポイント**:
- ローディングアニメーションが表示されているか
- ブラウザのコンソールにエラーが出ていないか（F12で確認）

### デプロイ後にアクセスできない

**原因**: デプロイ設定が正しくない

**解決策**:
1. 「デプロイを管理」で設定を確認
2. 「アクセスできるユーザー」が「全員」になっているか確認
3. URLが正しいか確認（`https://script.google.com/macros/s/.../exec`形式）

### 処理フロー

**フェーズ1: 分析**
1. ユーザーが求人広告を入力
2. フロントエンドが`analyzeJobPostingAPI()`を呼び出し
3. `JobPostingAnalyzer`が分析プロンプトを生成
4. `VertexAIClient`がGemini APIを呼び出し
5. JSON形式で結果を受け取り、正規化
6. フロントエンドに結果を返却・表示

**フェーズ2: サンプル生成（オプション）**
1. ユーザーが「サンプル生成」ボタンをクリック
2. フロントエンドが`generateSampleAPI()`を呼び出し
3. フェーズ1の結果をもとにプロンプトを生成
4. Gemini APIで改善サンプルを生成
5. フロントエンドに結果を返却・表示

問題が発生した場合は、以下を確認してください：

1. Google Cloud ConsoleでVertex AI APIが有効か
2. スクリプトプロパティが正しく設定されているか
